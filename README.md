# Responsive Student Management Portal (Bootstrap 5)

A fully responsive **Student Management Portal** built using **HTML, CSS, and Bootstrap 5**.  
This project provides an intuitive interface for managing student information including registration, dashboard analytics, profile management, and contact features.

---

## Project Overview

The Student Management Portal is designed to be mobile-friendly and responsive across all devices. It demonstrates the use of Bootstrap 5 components to build a professional and structured UI for academic management systems.

---

## Features

### Home Page
- Responsive Navbar with dropdown menu
- Hero section with welcome message and CTA button
- Feature cards:
  - Student Registration
  - Attendance Management
  - Results Management
- Footer with social media links

### Student Registration Page
- Full student registration form
- Fields:
  - Name, Roll Number, Email, Mobile Number
  - Gender, Branch, Date of Birth
  - Address, Photo Upload
  - Terms & Conditions checkbox
- Form validation using Bootstrap classes

### Student Dashboard
- Statistics cards:
  - Total Students
  - Present Students
  - Absent Students
  - Placements
- Student data table with:
  - Roll No, Name, Branch, Attendance
- Search functionality
- Responsive layout

###  Student Profile Page
- Profile card with image
- Student details:
  - Name, Roll Number, Branch
  - Email, Mobile Number

###  Contact Page
- Contact form with:
  - Name, Email, Subject, Message
- Bootstrap alerts for feedback

---

## Technologies Used

- HTML5

- JavaScript (optional for validation/features)

---

##  Responsive Design

The portal is fully responsive:

-  **Mobile (<576px):** Single-column layout, collapsible navbar  
-  **Tablet (≥768px):** Two-column layout  
-  **Desktop (≥992px):** Multi-column layout with full dashboard view
